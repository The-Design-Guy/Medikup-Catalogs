## Medium-duty shelving photos (מידוף לעומס בינוני)

- width (cm): 120, 150, 180, 210, 240 · height (cm): 200 (4 levels), 250 (5 levels)
- connection: `single` (יחידה בודדת), `row2` (2 יחידות בשורה), `b2b` (גב אל גב), `corner` (פינה 90°)
